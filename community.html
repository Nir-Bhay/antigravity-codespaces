Contribute to Antigravity Codespaces Pro

Last updated 21 October 2026

Antigravity Codespaces Pro is MIT-licensed and maintained on GitHub. Here is how to use it with an AI agent, report problems and contribute.

Star on GitHubForkOpen an issue
Agent setup prompt

Let your IDE's agent do the setup.

Paste this into the agent chat in Cursor, Google Antigravity, Windsurf or Codex. It follows AGENT_SETUP.md, asks you before signing in, and leaves your codespaces and SSH config alone.

agent-setup-prompt.txt
Set up the "Antigravity Codespaces Pro" extension (ID: nirbhay-hiwse.antigravity-codespaces) in this IDE so I can connect to my GitHub Codespaces over SSH.

Follow https://github.com/Nir-Bhay/antigravity-codespaces/blob/main/AGENT_SETUP.md step by step:
1. Detect which IDE and operating system this is.
2. Check that the GitHub CLI (gh) and an OpenSSH client are installed. Install whatever is missing.
3. Install the extension from Open VSX, or from the latest .vsix release if this IDE cannot reach Open VSX.
4. Install the Remote-SSH extension the guide lists for this IDE. In Windsurf, use the built-in SSH and install nothing.
5. Ask me before running "gh auth login -s codespace", and let me finish the browser sign-in myself.
6. Run "Codespaces: Setup Doctor", fix what it reports, and tell me exactly what you changed.
Do not delete any codespace and do not edit anything in ~/.ssh/config outside the blocks this extension manages.

Works with any agent that can run terminal commands. Review what it proposes before you approve each command.

Get involved

Ways to help.

Report a bug

Use the bug template. Attach the Setup Doctor report, which redacts GitHub tokens automatically.

Request a feature

Describe the problem first, then the change you would like to see.

Report a security issue

Please follow SECURITY.md and do not open a public issue.

Code of Conduct

We follow the Contributor Covenant 2.1. Read it before you take part.

Contribute code

Read CONTRIBUTING.md, fork, branch, and open a pull request using the template.

Improve the IDE guide

Tested it in an editor we have not covered? Add your findings with a source.

Browse open issues

See what is being worked on and pick something up.

Develop locally

Run it from source.

terminal
git clone https://github.com/Nir-Bhay/antigravity-codespaces.git
cd antigravity-codespaces
npm install
npm test          # runs the test suite
# package and install your build
npx @vscode/vsce package
code --install-extension antigravity-codespaces-*.vsix
