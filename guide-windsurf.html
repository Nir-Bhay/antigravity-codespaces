GitHub Codespaces in Windsurf (now Devin Desktop): what works and what to avoid

By Nirbhay Hiwse · 21 October 2026 · 5 min read

Short answer: Windsurf (now Devin Desktop) has its own built-in SSH. Windsurf's documentation now uses the name Devin Desktop; whether the app itself has been renamed is not confirmed. The editor supports Linux hosts over SSH, and its documentation asks you not to install Microsoft's Remote - SSH or open-remote-ssh because they conflict. Codespaces run Linux and are reached through the GitHub CLI, so install gh and this extension, add no other SSH extension, and keep the manual SSH command as a fallback.

How does Windsurf handle SSH?

Windsurf's advanced configuration documentation (the page now carries the Devin Desktop name) states that Windsurf supports SSH into Linux-based remote hosts only, and that the usual Microsoft “Remote - SSH” extension and the open-remote-ssh extension will not work and should not be installed, because they conflict with its own support.

Where do codespaces fit?

Codespaces run Linux, which suits Windsurf's SSH. The connection goes through gh codespace ssh --stdio as an OpenSSH ProxyCommand, as described in the GitHub CLI manual. GitHub's own Codespaces extension is not available here: the Open VSX API returns not found for GitHub/codespaces.

What has not been confirmed?

Windsurf's documentation does not say whether its SSH honours a custom ProxyCommand in ~/.ssh/config. This guide therefore makes no claim that Quick Connect works in Windsurf. If it does not, use Copy SSH Command and connect from a terminal, or open the host cs.<codespace-name> from Windsurf's remote menu.

How do I set it up?

  1. Install the GitHub CLI and run gh auth login -s codespace.
  2. Install the extension: windsurf --install-extension nirbhay-hiwse.antigravity-codespaces.
  3. Do not install any other Remote-SSH extension.
  4. Run Codespaces: Setup Doctor. From 5.3.1 it recognises Windsurf by its built-in extension codeium.windsurf-remote-openssh, or by “windsurf” or “devin” in the app name. If the built-in SSH is not enabled, it says so and points to that extension rather than to open-remote-ssh.

FAQ

Is Windsurf now called Devin Desktop?

Windsurf (now Devin Desktop, in its documentation): the advanced configuration page is titled “Devin Desktop - Advanced”. The documentation uses the new name; this guide does not claim that the app itself has been renamed.

Do I need another Remote-SSH extension in Windsurf (now Devin Desktop)?

No. Use the built-in SSH and do not install Microsoft Remote-SSH or open-remote-ssh, because they conflict with it.
